# Setup lmms-eval Environment

Execute the following commands in order:

1. Source the bash configuration:

```bash
source ~/.bashrc
```

2. Activate the Python virtual environment:

```bash
source /data1/wenjie/projects/lmms-eval/eval/bin/activate
```

Both commands must succeed before proceeding with any lmms-eval tasks.
